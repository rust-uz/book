# 1-Bob: Ishni Boshlash (Getting Started)

Rust olamiga sayohatingizni boshlaymiz! Bu bobda biz:

* Linux, macOS yoki Windows operatsion tizimlarida Rust muhitini o‘rnatishni,
* Dunyodagi har bir dasturchi yozadigan an’anaviy *"Salom, Dunyo!"* dasturini Rust da noldan yozish va kompilyatsiya qilishni,
* Rust ning rasmiy paket menejeri va loyiha yig‘uvchisi — **Cargo** vositasidan to‘g‘ri foydalanishni o‘rganamiz.

Rust dasturlash tilining eng katta kuchi — uning asboblari (tooling) mukammalligida. Ishni boshlashdan oldin kompyuteringizda terminal (komandalar qatori) bilan ishlash bo‘yicha minimal tajriba yetarli.

Keling, avvalo Rust ni kompyuteringizga o‘rnatishdan boshlaymiz!
