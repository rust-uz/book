# Kirish: Rust Dasturlash Tili

> **Eslatma:** Ushbu kitob rasmiy *"The Rust Programming Language"* (Steve Klabnik, Carol Nichols va Rust jamoasi) kitobining O‘zbekiston Rust hamjamiyati (**Rust Uzbekistan / rust-uz**) tomonidan tayyorlangan ochiq manbali o‘zbekcha tarjimasidir.

Rust dasturlash tiliga xush kelibsiz! Rust — bu har bir kishiga ishonchli va yuqori unumdorlikka ega dasturiy ta’minot yaratish imkonini beruvchi tizimli dasturlash tilidir.

## Rust Kimlar Uchun?

Rust ko‘plab sabablarga ko‘ra har xil turdagi ishlab chiquvchilar uchun ideal vositadir.

### Talabalar va Yangi Muhandislar
Rust — bu kompyuter muhandisligi, operatsion tizimlar va apparat darajasidagi tushunchalarni (xotirani boshqarish, CPU keshlar, ko‘p oqimlilik) o‘rganish uchun ajoyib tildir. Rust yordamida siz C yoki C++ dagi kabi "Segmentation Fault" yoki xotira sizib ketishi (memory leak) xatolarisiz xavfsiz past darajali kod yozishni o‘rganasiz.

### Tizim Dasturchilari (Systems Developers)
Agar siz operatsion tizim yadrolari, fayl tizimlari, o‘yin dvigatellari yoki yuqori yuklamali tarmoq serverlarini qursangiz, Rust sizga Garbage Collector (GC) siz **C/C++ tezligini** va shu bilan birga **xotira xavfsizligini** beradi.

### Veb va Backend Dasturchilari
Rust Tokio, Axum va Actix-web kabi asinxron freymvorklar orqali soniyasiga yuz minglab so‘rovlarni (RPS) minimal RAM va CPU sarflagan holda qayta ishlash imkonini beradi.
